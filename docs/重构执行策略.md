# 浮生流年 重构执行策略

## 总原则

"让 AI 写出像真人写的小说" = 修复四个技术断层 + 增加三层控制。

### 四个技术断层（Phase 0 修复）
1. 温度与格式：正文已纯文本+分温，已验证
2. 长程记忆：冷热分层衰减 + 滚动摘要链 + pgvector 配置
3. 质量门：三级负面清单替代 13 道门，单章失败不暂停全书
4. 写作指导：method card 发布 + 向量检索

### 三层控制（Phase 1 实现）
1. **意图层**：创作宪章 + 8 步意图访谈，锁定你的心意
2. **规划层**：六层大纲（L0-L5）+ Beat 卡，每层可看可改可锁定
3. **反馈层**：用户改稿 → taste 蒸馏 → AI 越来越懂你

## 执行顺序

Phase 0（止血）：第 1-2 天 → 立刻部署
Phase 1（心意）：第 3-7 天 → 分步部署
Phase 2（记忆）：第 8-14 天 → 分步部署
Phase 3（知识库）：第 15-21 天 → 分步部署
Phase 4（反馈飞轮）：第 22+ 天 → 持续
