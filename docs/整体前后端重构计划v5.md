## 第〇部分 一句话总纲

**把"网文大神的方法论"编译成系统的数据结构与流程约束，让用户在每一层（类型→风格→文笔→大纲→章节→段落）都拥有"可看、可改、可锁定"的控制权，AI 在被锁定的约束内全力发挥。**

傻子变大神的原理：大神与新人的差距不在文笔，而在**方法论纪律**（大纲分层、爽点节奏、伏笔回收、开篇漏斗、负面清单）。系统把纪律固化成机器执行的流程，把品味留给用户选择。

## 第一部分 方法论底座（素材库 → 可产品化规则）

这是本次重构最大的增量：500 份素材提炼出的规则，逐条映射为系统能力。

### 1.1 大纲六层模型（核心数据结构）

素材共识：大纲从粗到细分层，"先骨架后肌肉"。

| 层 | 名称 | 粒度 | 系统对应 |
|---|---|---|---|
| L0 | 点子/一句话创意 | 一句话 | 意图访谈第一问；四种套路（新旧瓶×新旧酒） |
| L1 | 立意/核心梗 | 几十~几百字 | 主角追求+行为方式即立意；决定结局与每卷结尾 |
| L2 | 作品设定 | 数千~数万字 | 世界背景/力量体系/角色/势力（= Project Seed 事实包） |
| L3 | 故事主线 | 串珠式事件链 | "预设目标链"（村长→镇长→…→主席），主线一/二+暗线一/二 |
| L4 | 分卷/阶段规划 | 每段数百字，覆盖数万字 | **"几十章粗略规划"就在这层**：编号事件段（主线N+支线），非逐章细纲 |
| L5 | 章纲 | 每章 50~500 字 | 按需展开，写前一批一批生成 |
| L6 | Beat 卡（情节构思卡） | 章内 beat | 来自写书总结表.xls，见 1.3 |

**关键设计结论（来自范例分析）**："几十章粗略规划"的正确形态是《一万字无线玄幻文大纲模本》式的**编号事件段**（每段=主线推进+若干支线，约等于 5~7 章的章群），首屏给用户"阶段地图+每段关键词/爽点/坑"，用户改的是"段"而不是章。

### 1.2 九线维度（规划内容的完整性检查）

所有情节从九线衍生：**主角智慧性格 / 配角炮灰 / 技能 / 伙伴 / 装备 / 冒险 / 身世 / 势力 / 后宫（感情）**。

系统用法：
- L4 事件段生成时，AI 必须标注每段覆盖了哪几条线；
- 蓝图工作台提供"九线视图"：每条线一条泳道，一眼看出哪条线断更了几十章；
- 完整性 lint：连续 N 段未推进感情线/身世线 → 黄色提示。

### 1.3 Beat 卡 —— 章内情节构思卡（来自写书总结表.xls，重要新增）

每个情节单元（约一章或半章）由固定字段构成，AI 写章前先生成这张卡，用户可改卡再生成正文：

```
前设/铺垫（前提条件是否充足） → 外部矛盾 + 内部矛盾 → 主角目的 / 对手目的
→ 主角面临的困难 → 衬托 / 对比（反差原理） → 压抑（蓄力） → 底牌/金手指出现
→ 神转折（A骗读者→以为走B→实际走C） → 出风头 + 得好处（一个好情节两者至少各一次）
→ 读者期待感落点
```

**装逼四步布局**（标准爽点执行流程，可直接做成 prompt 模板）：
1. 必须有装逼方、被装逼方、观众三角色；
2. 事前极力抬高对手、贬低主角（反差越大越爽）；
3. 事中主角淡定，对手从不屑→震惊→极度震惊→膜拜；
4. 事后主角不以为然，观众品头论足完成地位互换。
高级变体（射雕比武招亲）：主角可以羞窘而非淡定、骗过读者以为必输、胜后引出更大人物拔高剧情。

### 1.4 爽点节奏引擎参数（素材一 + 教程16）

| 参数 | 取值/规则 | 来源 |
|---|---|---|
| 爽点类型 | 暧昧(先抑后扬)/物品获得(强化存在感)/养成/优越感(扮猪吃虎)/送菜流 | 小说爽点 1-3 |
| 位置布置 | 头尾型（开头亮金手指；每 3-6 万字一个"小结尾"爽点）/ 高潮型（压制到极限再爆发，忌频繁）/ 成长型（早埋种子多线错开开花） | 爽点位置布置 |
| 节奏公式 | 三章一小高潮、五章一大高潮；男频阶梯式、女频心电图式 | 教程16 |
| 节奏调节 | 太快→补描写细节；太慢→删场景/合并/叙述代描写 | 教程16 |
| 单位密度 | 情节密度按字数计，注水检测 | 教程16 |

系统用法：`pacing_configs` 表存每本书的节奏参数（用户可调），L4/L5 生成时作为硬约束；成稿后自审时按窗口统计爽点密度并告警。

### 1.5 伏笔纪律（素材一 + 教程17/18）

- 网文连载特性：伏笔**宜少、宜浅、易被看出**；埋设与回收间隔不能太久，间隔中要多次提及唤醒记忆；
- 有伏必有应，别让伏笔只当伏笔（同时承担别的功能）；
- 推荐"**无目的 YY 伏笔**"：主角先获得来历不明的物品，作者后置决定用途——完美适配 AI 滚动写作；
- 载体三类：人 / 物 / 对话。

系统用法：`plot_ledger`（伏笔登记表）为一等公民：埋设点/提及点/回收点/载体/状态。自审 gate 检查"回收间隔 ≤ N 章""到期未回收"并阻塞或提示。

### 1.6 开篇漏斗（教程8 + 开篇1/2 + 主编红线）

前三万字硬规则（可做成"开篇模式"，前 10 章生成时自动加严）：
- 开篇四要素强制校验：主角 / 主线 / 伏笔 / 首个矛盾冲突（用对比呈现）；
- 主角戏份 ≥ 50%，开场出场人物 ≤ 5，少给龙套起名，设定从简；
- 第一时间亮时代背景 + 金手指；
- 五种开局法可选：先抑后扬(废柴流)/先扬后抑/复仇报恩/烘托法/楔子伏笔法（楔子必须极短）；
- 章末强制悬念（蔡格尼克效应：未完成的事印象更深）。

### 1.7 主角与金手指

- **泛性格原则**：主角只给"有毅力、懂隐忍"式泛性格 + 1 个特异标记，留白给读者代入；配角反而要生动；
- **金手指五特性**：唯一性 / 限制性（初期弱随节奏开大）/ 保密性 / 简单性 / 成长性；不宜多开，不能依赖（核心是主角自身成长）；
- **角色主动行为三层模型**（素材二）：行为由性格驱动→由目标驱动→由处境反推。

### 1.8 负面清单（AI 自审规则集，替代现有 20+ 条僵硬禁令）

汇总为三级：

**A 级（阻塞，生成后必须修复）**
- 绿帽/虐主超一章不翻盘（如写必须同章翻盘且主角得好处）
- 主线消失 / 万能主角 / 剧情涉政涉黄（主编枪毙理由）
- 逻辑硬伤、人物身份混乱（三人以上对话无指示）

**B 级（警告，建议修复）**
- 五大失败描写：主角幼稚 / 擂台连篇 / 睡醒变身 / 史官评价 / 书中书堆背景
- 感叹号流升级（每次升级都写成高潮）
- 类型混杂（都市+修真+西幻乱炖）
- 升级体系过度复杂（应套成熟体系换称呼）
- 对话太白（要么搞笑要么有深度；高手对话精简+动作表情）
- 引号开头段落连续过多；长句长段

**C 级（风格提示）**
- 形容词堆砌、外貌描写超长、水文注水

### 1.9 类型知识包（Genre Pack）

每个类型一个知识包，创建时选定后注入全流程 prompt：

| 类型 | 核心规则（素材二提炼） |
|---|---|
| 玄幻 | YY 七要素（奇遇/升级/泡妞/寻宝/发财/欺人/助人）；打斗七公式；退婚流 Beat 参考 |
| 都市 | 装逼细则：装的理由先行、反派越NC越好、必须有观众、连环装 |
| 女频 | 双线（自身成长+感情线）交融；排名体系体现升级感；心电图节奏；换地图先铺垫 |
| 网游/科幻/武侠/悬疑/官场/军事/历史 | 各自类型规则（素材二类型知识图谱） |

配套通用工艺：世界观要素表（自然：地理地形气候；人文：政治经济阶层职业种族宗教）、心理四法（直接描写/内心独白/多角度衬托/环境衬托）、对话四形式轮换+潜文本、铺垫三类（人物/情节/气氛）。

### 1.10 RAG 素材库（描写检索库）

| 库 | 内容 | 用法 |
|---|---|---|

## 第二部分 产品流程重构（用户视角）

### 2.1 新建一本书（意图访谈 → 蓝图工作台）

```
Step1 点子       一句话也行，一个词也行。AI 用"四种套路"帮扩写出 3 个方向供选。
Step2 意图访谈    对话式（非表单），逐层收敛，每步都有 AI 推荐+可跳过：
                  类型(挂载 Genre Pack) → 基调/文风(给对照样张选) → 主角(泛性格+特异标记
                  +追求) → 金手指(五特性问答表) → 世界观(地图破局式：先画地图再问势力)
                  → 篇幅目标 → 结局倾向
Step3 顶层锁定    生成《意图书》(intent_brief)：类型/基调/文笔/力量体系/主角追求为
                  "锁定字段"，后续所有生成严格遵守，改动需用户显式解锁。
Step4 蓝图生成    AI 依次产出 L1 立意 → L2 设定 → L3 主线(预设目标链) → L4 事件段规划
                  （首期 20~40 段 ≈ 前 100-200 章的粗略规划），每段含：关键词/覆盖九线/
                  预埋伏笔/爽点类型与落点。
Step5 蓝图工作台  用户逐层查看与编辑（见 2.4），满意后点"开写"，进入章节循环。
```

**傻子模式**：每一步全部接受 AI 推荐，5 分钟走完，得到一套完全符合方法论纪律的蓝图。
**大神模式**：每一层每个字段都可手改、可锁定、可要求 AI 重新提案。

### 2.2 导入一本书（Work Codex → 殊途同归）

```
Step1 上传解析    分章 → 清洗 → 入库。
Step2 Codex 构建  四层拆解（v4.1 设计保留，用六层大纲模型增强）：
                  事实层：人物/势力/地点/物品/时间线（→ L2）
                  叙事层：反推 L3 主线 + L4 事件段 + 九线覆盖图 + 伏笔登记表
                          （已回收/未回收的坑单独列出——续写的命脉）
                  风格层：文风样本、对话形式分布、节奏曲线（爽点密度实测）
                  DNA 层：类型/套路/金手指结构/装逼模式（用 1.9 类型包做模板匹配）
Step3 选择用途    续写：沿用全部四层，未回收伏笔进入 plot_ledger 待回收；
                  仿写：抽 DNA 层+风格层，事实层重置，走 2.1 的 Step2 起点预填；
                  同人：保留事实层+DNA 层，用户改主线，L3/L4 重新生成。
Step4 殊途同归    三种用途最终都生成同一份 Project Seed（四包），进入同一个蓝图工作台
                  和同一个章节循环。原著 Codex 成为该项目的专属 RAG 知识库，写作时
                  Context Pack 自动检索注入。
```

### 2.3 章节写作循环（状态机 + Beat 卡）

```
BRIEF(章纲) → BEAT_CARD(情节构思卡) → GATE(前置检查) → DRAFT(生成正文)
→ SELF_REVIEW(负面清单三级自审 + 节奏/伏笔 lint) → DELIVER(交付用户)
→ FEEDBACK(用户改稿/评价 → 反馈飞轮) → PUBLISH → COLLECT(回写 wiki/摘要/伏笔状态)
```

与 v4 的差异：在 GATE 与 DRAFT 之间插入 **BEAT_CARD** 状态——AI 先出一张 1.3 的构思卡（200 字以内），副驾挡下用户可 10 秒扫一眼改两笔再生成 4000 字正文。**这是"控制感"成本最低、收益最大的一环。**

三挡控制（v4 保留）：自动挡（卡片全自动通过）/ 副驾挡（默认，卡片停留供改）/ 手动挡（每个状态都需确认）。

### 2.4 蓝图工作台（前端核心新页面）

- **阶段地图视图**：L4 事件段横向时间轴，每段一张卡（关键词/爽点标记/伏笔标记/覆盖九线的彩色点）；拖拽调序、点开改文案、"对这段不满意→AI 重出 3 版"。
- **九线泳道视图**：九条泳道 × 事件段，断线一目了然。
- **伏笔登记表视图**：埋设→回收连线图，逾期未收的坑标红。
- **层级树视图**：L0→L5 树形展开，任何一层改动后可"向下重推"（只重生成受影响的子层，弹 diff 供确认）。
- **版本分叉**："大纲是活的"——写作中偏离大纲时（用户改稿或 AI 提议更好情节），支持从当前章分叉出新蓝图版本，旧版本保留可回滚。
